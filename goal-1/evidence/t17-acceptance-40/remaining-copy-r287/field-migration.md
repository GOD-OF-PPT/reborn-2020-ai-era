# 削减重复说明前的完整去处

| 原字段/事实/动作 | 第一层 | 完整说明与不变约束 |
|---|---|---|
| 架空性质/主体/可花/保护/日期 | 原性质/owner，记录仍原日期与身份 | 原册同run/account/business/record，失效明确重选 |
| 两种准备与前提 | 500/1500、各1点/7天、显选项目 | 实际关系/授权/融资意愿/资格分别核，不保证股份 |
| 实际资源/开工日期/可用与预留、0AP/过期草稿 | 原字段及异常理由保 | 原preview/原捕获确认，未来季预算不冒本季 |
| 介绍来源/0费用/0AP/窗口次数 | 来源显选与0承担 | 未核授权/意愿、后续调查/中间费/拒绝各原确认 |
| 谈判费用/AP/7天、取得方式/本金、三条款权利/锁定 | 实际报价/权利比较、所有原字段显选 | 投前/新资本/不增资本的老股/可能拒绝与原锁定完整展开 |
| 已回应/拒绝/过期/closed、本金/股数/原期限 | 当前阶段/本金/份额/期限，原签或放下 | 不把报价当支出；独立Sign/Decline原确认，未来/已签仍原拒绝 |
| 放下条款的原零新增、原本金没支付、历史费用与未完任务 | 同捕获确认首层解释 | 沿唯一原n/i/b/view，未完job不自动停止，未知不补零 |
| 原job日期/真实status/中断/固定改期拒绝 | 阶段/日期与短动词、原理由 | 原Interrupt/Reschedule不改，完整已付/预留/原任务保 |
| 资金转移/资本、停止/关闭全部任务/员工跨业务影响 | 转移不算利润、实际影响常显 | EquityBusinessContinuity完整保、原捕获共享确认/原资产义务 |
| Today、原记录/原主体/各协议、原账/两种生命周期操作 | 短阅读动词，重要停止选择 | 不自动新业务/换主体/清义务/释放资金；所有原入口保 |

记录行继续准确身份和日期，可用原阶段短标题减少重复句，未知/失效保原完整原因。未知资金/保护/责任例外不受字数预算。所有显示理由不控制资格或执行门槛。
