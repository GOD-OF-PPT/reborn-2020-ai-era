# 首层与完整条件的对应

| 首层 | 真实去向 | 继续可见/可核的依据 |
|---|---|---|
| 看看合作条件 / 先看条件·暂不投入 | 原open近景，未执行GameCommand | 自有资本空稿、资本转移而非费用、模型节点、生活与维护、原确认 |
| 看看架空出资 / 独立选择·查看不出资 | 原equity入口、个人账户，目标null | 不先开服务企业；原准备与已有协议独立选择 |
| 准备服务材料 / 备好后再决定接单 | 同business材料资源日期近景 | 原300元/1点/7日、空资源/日期、取消保稿与原确认 |
| 安排技术学习 / 学完另选用途与客户 | 同business技术学习 | 原1000元/1点/7日、实际资源/日期与原预览 |
| 选择模型与用途 | 同business适配 | 虚构许可、500元/1点/7日、明确用途同意；不是股份或真实授权 |
| 核对收款金额 / 到期后自选金额 | 同delivery原收款 | 原应收/已消费预款/信用/未收/到期日、空金额、原实际收款确认 |
| 补救还是退出 / 退款与补偿 | 同contract原回应 | 已付/预留、一次补救、补救和支持合计费用/AP、退款/补偿分别核 |
| 回到今天 / 经历留在手记 | 原Today阅读视角 | 不撤原约；原金额/日期/AP/书签/记录保持 |
| 翻合作手记 | 同run/account/business/target原册 | 全部原journey、操作字段、逐笔记录、原权限 |

纸件只更换可见actionHint，binding.activate/disabled/label保持同原共享对象。原command/Clock分支不改文字或日期；所有动态事实/未知说明不截断。固定完成提示不暗示一定还有欠款，也不暗示已关闭企业仍在营业。
