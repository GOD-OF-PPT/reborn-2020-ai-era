## 整幕的变化

常态不再把左半屏当说明文章。城市与人物保完整，桌前是可辨认的完成教案，近处有木托架、压页笔和接触影；成果是主视觉，当前问题只说“样课做好了。下一段时间，想留给谁？”一个短注说明尚无学员。教案只留“样课已完成”一枚短签，不再附同义按钮框或多条长标签。

两个具体去向在靠近前景的下方以念头出现：①“先了解，谁可能需要这堂课”只打开来源/拟报价；②“把样课收好，回到今天”只改UI阅读位置。物件点击与①绑定同一原动作。Clock在另一侧以日期动词独立可达；完整记录与日历保房间固定阅读位置。资金不足在真实选择付费模式时明确，不把查看按钮禁用成无路可走。

| 旧内容 | 留/移/去重 | 新的可见位置与理由 |
| --- | --- | --- |
| 愿望＋当前尝试长句 | 愿望留短句；本次阶段不再复述 | 左上日期下轻文字；人生方向与本次成果分层。 |
| 标题、阶段、正文多次“样课完成” | 合为一句事实＋教案短签 | 场景上方一句“样课做好了”；前景教案是实物结果。完整历史进原册。 |
| 准备与招生边界长段 | 本幕保“还没有学员”；费用/来源进入决定面 | 不删真实限制；付费不足、视频来源资格在相应选择处可见，后续班额/支持不提前成为本幕表单。 |
| 泛称“怎样继续”主按钮和右同义框 | 换两条具体去向；去掉重复框 | 前景附近念头，①与教案同动作，②回今天。不能让①再开摘要。 |
| 企业可花/共享AP/保存 | 保持一组 | 右上清楚并列账户和资金性质；切主体仍原确认/显选，行动不重置。 |
| 原Clock与核对 | 保原动作/预览/确认 | 右下明确日期“让日子继续到2023-01-20”，不偷偷推进。 |
| 到期责任/缺口/候选/冲突 | 不删、不只留AX、不混成一条优先签 | 有责任就在日期下独立显示；无责任不画假警告。本稿基线不新增责任。 |
| 完整原账/随身册/日历 | 保同对象与原分页 | 场景边缘独立阅读入口；不与纸签重叠，不滚动或裁切。 |
