# D12实施路径独立复核

先把“重来一次，想怎样生活”贯穿到下一季，再扩展经营表现。沿A长日重启、两背景、五路线、24季度、四AP与一屏分页；原账完整可达。以下均为待实施、待试玩的门槛。

1. **重来的一天（起点）。** 背景与愿望进入住处，首封委托明确客户、成本、行动与日期；接单、拒单、保留工作都能继续。将来信、制作文件、发送记录、回款分别做成真实状态物件。验收：玩家能解释为什么接或不接；接单者实际经历制作、提交、复核、到账，重进一致，不把安排演成成功。
2. **我选的第一季（依1）。** 用当季公开处境连接愿望，突出一项可调整的关注；工作、模拟投资、生活可组合，五路线仍可自由查看。完整走过工资日、订单撮合/交收或生活约定，季末回响接下一次选择。验收：玩家能说出舍弃了什么、正在等谁及哪日反馈；持股未卖也能继续，未完成承诺跨季保留。
3. **从一份作品到生意（依2）。** 先闭合视频的选作品、资源/日期、制作、返工、验收、回款；再独立闭合课程的大纲、样课、招生、教学/支持与退款。按年代逐段换入人物、道具和原创路线卡。验收：同对象往返不丢草稿；玩家能区分播放、作品完成、案例可用、学费保护与可花现金；转课程始终可选。
4. **把服务与控制握在手里（依2、3的呈现接缝）。** 各自闭合中转服务周期、生态合同与明确架空权益的一次投入到实际反馈；给许可、原账单、独立回信不同物件。验收：完成不等于收入、应收不等于到账、估值不等于现金；采用支持、扩权、有限停止分别决定，不采用代理也能通关，不强制危机。
5. **这些年留下了什么（依1—4）。** 将季度、年度和2025回顾连接实际选择，以真实生活改善、共同经历、已完成作品改变场景；尾声仍面对旧责任。验收：正常两背景连续游玩可解释准备如何影响后续；玩家能指出一项愿望的得失，完整24季及未结义务另有实际证据。

接缝：Home/RoomMoment/NarrativeScene承载目的与焦点；各scene-progress及projectWorkbench只整理公开事实。复用App.request→原preview/确认/submit→RunSession.view→savedSceneResult，结果动效与声音等保存后触发。新增导航须携带run/账户/业务/作品身份；责任行只传screen可能换错对象，状态优先级变化也可能抢走玩家焦点，均须逐片核查。
