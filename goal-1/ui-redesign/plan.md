# Goal 1 补充｜完整界面、流程与视觉重构

依据2026-10-17用户原话，input.md逐字保留。沿用现有goal，不重置T01—T13、原始input/plan或历史证据。此补充对后续前台实施次序优先；原计划仍为完整游戏范围权威。

## 需求与问题

现有界面能操作规则，但十个同级入口、持续展开的表单/说明、重复的摘要和按钮、无场景叙事及薄弱的阶段反馈，使游戏像工程控制台。重构必须同时覆盖信息架构、开局/季度/经营/财务/事件/异常/结果流程、视觉系统、场景资产与动效，不只更换CSS配色。

延续05的半写实电影感方向：2020普通出租屋、克制冷暖光、清楚的平面工作台。图片承担空间与情绪，可变中文/金额/按钮仍由HTML绘制。新生成图独立编号，不能冒充三张缺失原PNG，也不自动完成P022或试玩。

## 路径与边界

顺序调整为T13 → D01设计与交互样稿 → D02正式前台重构及累计检查 → T14历史/危机 → T15人物/年度/正式界面补全 → T16整局 → T17验收 → T18候选。只执行当前一个任务。

D01本轮交付：现有界面与流程审计、完整设计合同32、内置image_gen生成的独立场景/视觉方案图、可在浏览器切换主要状态的高保真HTML样稿、素材提示词/来源/尺寸/哈希、实际桌面/窄屏/键盘/减少动效检查。样稿使用明确标记的固定UX01示例，不调用游戏规则、不读写真实存档、不声称重构已经接入运行时。

D02接入既有React/Controller/只读features：分组导航、渐进开局、季度简报/计划/抉择/结果、五路线不同操作、两层财务、合同/例行/异常与失败候选，统一组件/表单/确认与视觉反馈。真实命令签名、金额/资格/随机/日期/IDB原子性不改变。覆盖全部已有页面，不只首页。原角色/危机/年末功能仍按原任务实施，设计中规定其容器与交互，禁止用假功能代替。

D02后做T13+D01+D02的累计全面检查；原C15保留，另在T16做T14—T16累计检查，覆盖新增任务后的每三项节奏。D01内部审计/生成/样稿三步骤后有一次全面设计检查。

## 视觉与流程

暖灰纸面、墨色正文、黄铜强调，少量年代冷蓝；房间为氛围层，操作为可读平面。主导航收敛为本季、经营、记忆、账本；五路线在经营中持续可发现，例行计划从本季与经营可达。

开局先进入房间，再选择背景/愿望与可跳过的建议；季度先回答现在可花、已承诺什么、下一步需要决定什么。普通重点1主2支只控制强调，全部到期义务与独立风险仍在显式队列。结果用回款/成本/净额/剩余承诺讲清变化，已完成/待验收/待回款分开。融资与AI权限永远独立确认。

动效仅限150—240ms的淡入、面板位移和结果数字状态转换；无实时倒计时、自动推进、强制长转场或随机装饰。减少动效与文本模式不得改变规则或遮住错误。

## 风险、验证与回滚

主要风险：美术压过信息、一次性重写丢入口/旧义务、生成图乱码/时代错位、示例被误认成真实游戏、存储失败被动画伪装成功。分别用对比度/桌面首屏、完整页面迁移表、图片人工查看、样稿永久标识、真实失败态与跨版本存档操作验证防守。

D01验证：资料检查，原资料/历史哈希保持；两张生成图实看并记录；样稿实际浏览器检查关键状态/导航/对话焦点/宽窄屏与减少动效。此阶段不运行无关全部408项引擎测试，也不把样稿当作真实引擎/用户试玩。

D02验证：受影响UI/控制器测试、类型/构建、全部既有规则回归、两背景真实浏览器/键盘/目标视口、保存失败/刷新/双标签/导入恢复、分账/预款/义务/退出与几条实际经营链。按真实证据分层报告，不降低测试时限或改历史样例。

回滚：D01资料和样稿独立新增，不碰运行时或原素材；D02按提交边界用新还原/修复提交回退前台，保持存档和命令合同。素材与旧审计文件不可原地覆盖，不推送或公开部署。

[杠精审查] 计划通过：明确全页面/全流程和效果范围、运行时接入责任、资产与示例边界、保存/随机/账目不变量；D01交付可评审的真实视觉和交互产物，D02不能只改颜色或首页。
