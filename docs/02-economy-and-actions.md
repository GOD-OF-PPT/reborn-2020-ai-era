# 02｜行动、经济与结算

所有金额、行动点和样例结果均为平衡测试初值，不是已确认产品数值。

## 时间与行动

每季度4个个人行动点。全职工作占2点；学习、调查、关键社交或休整通常占1点；重要产品阶段通常占2点。不同背景与雇佣人员的能力可以改变项目执行条件，但不让个人关键谈判和判断变成无限免费行为。

阅读新闻、账目、记忆与选项免费。基础季度调仓不占个人行动；深入尽调、争取融资参与权或谈判要占行动。一个行动被事件复用时必须标注替代关系，不能重复收费，也不能免费赠送新的季度。

建议状态：draft → committed → executing → interrupted/completed → settled。草稿可撤回；已执行部分不可无成本撤销。重大危机只可重排未执行行动。

## 两套账户与三种个人资产

个人：现金、可出售投资、非流动股权。公司：现金、待收款、固定支出、项目支出、融资与债务等独立记录。

总身价不等于生活储备；账面收入不等于现金到账；公司融资不等于创始人个人收入。出售投资时同时减少对应持仓并增加扣除模拟费用后的现金，不能将出售额又加进总资产收益。玩家注资必须生成相同金额的个人转出与公司转入记录。

原型可以简化税费与交易制度，但要明确为模拟规则，不能声称真实历史收益。所有内部金额使用整数最小货币单位，展示层再换算元，避免浮点误差。

## 现金预览与月度约束

季度是决策粒度，不意味着季度末现金为正就能自动支付季度中的全部费用。为大额支出记录发生时点；必要时按月处理工资、房租和公司消耗，以防“先用尚未到账的工资投资”的漏洞。

界面展示可动用现金、已承诺支出、预计回款与最低现金点。续航提示必须说明是否计入不确定回款；不确定回款不能当作保证到账。

## 新手季度的固定核算样例

期初个人现金30,000；三个月工资24,000；生活费用12,000；学习支出3,000；投资买入12,000。期末现金27,000。若投资市值变为11,000，现金与可变现投资合计38,000，不应将持仓再按买入成本重复计算。

全部工作2点、学习1点、帮助合作伙伴1点；查看与基础调仓免费。上述期初现金足够覆盖例子中的初始支出，月度支付时序仍需在实现中测试。

## 创业季度核算样例

期初公司现金300,000；项目投入80,000；固定支出150,000；客户回款60,000。期末公司现金130,000。该例不是完整公司利润表，也未包括其他可能科目。

## 失败与恢复

现金不足时先进入有明确期限与条件的恢复路径：收缩成本、卖资产、协商延期、重新就业、接受收购或接管。不得允许无限负现金、凭空注资或反复领取同一事件回款。某些恢复选项可能保住公司却稀释或转移控制权。

生活状态：稳定、紧绷、透支。持续透支会事先提示并影响效率与关系。恢复有成本；不要用随机重大疾病代替经营取舍。

## 必须测试的不变量

- 行动成本来自同一个季度预算；项目与危机不能同时使用同一份团队时间。
- 相同事件实例和结算事务只执行一次；读档不能重复收款。
- 个人注资和公司入账成对；未实现股权升值不产生现金。
- 股权总额与融资稀释关系可解释；控制权不等于简单财富阈值。
- 所有交易和结算都有来源ID、发生时点、账户与因果说明。
