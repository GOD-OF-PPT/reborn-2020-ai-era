# 02｜行动、经济与结算 v0.3

本页是金额、行动与时间的权威工作契约；v0.3替代旧版本中未明确的占款、退款和退出口径。原型使用人民币整数分、比例万分比，内部金额上限为9000000000000分，乘除使用经检查的整数运算或临时大整数；禁止浮点累积。所有数值为模拟，不构成现实交易或财税指导。

## 1. 时钟与行动

2020—2025年共24季度，每季4点。计划只预留，不产生收入。动作有plannedAt、startAt、completeAt和settlementAt；日期等待与个人行动分离。全职工作开始消耗2点，工资月末到账；辞职只停止未取得的后续工资，行动不返还。生活支出在月初到期。

同日处理顺序固定：世界状态更新 → 已到期确定到账 → 到期付款/义务 → 可选玩家动作 → 本检查点交易撮合 → 快照。同类按priority、instanceId稳定排序。推进不能跳过事件、付款缺口或需要决定的节点；不看新闻不改变世界。

在本检查点看到结果后下的订单，最早进入下一有效撮合点；不能按先前价格成交。模拟交易检查点规则与真实A股回放分离。季度收入预估只供计划，不用于透支月初支出。

行动生命周期：draft → reserved → executed → completed/interrupted。执行成功扣行动并转换预留；取消仅释放未执行部分。中断记录已完成产出、已付成本及仍待履约部分，不能同时领取原动作和替代动作的全部收益。

维护、调查、制作、关键交付和危机共用预算。团队产能是独立的带日期资源，不能与个人行动重复计算。执行前同时检查本人的注意力和项目所需产能；同一员工同一时间段不能分配给两份满负荷任务。

## 2. 账户与资金保护

个人、每个企业独立账本；个人副业以businessId分账，不强制注册公司。注资、借款、分红明确类别并成对记录。客户、供应商、市场等外部主体也用虚拟对手账户配平，不接触真实资金。

现金占用采用唯一reservationId，同一分现金只能处于一个占用桶：客户保护、司法/风险冻结、待执行计划或待成交订单。计划转订单时移动同一占用，不新建第二份。不可把订单冻结再重复算作计划预留。

可动用现金 = max(0, 现金余额 - 各互斥占用桶合计)。若冻结或应退保护要求超过现金，另显示资金保护缺口，不用max掩盖资不抵债。到期欠款独立列示，禁止负现金“假装付完”；阻止新扩张但保留应急、减支、融资或清算路径。

首版采用保守的游戏保护规则：未交付预付款不能炒股、分红或支付其他项目。交付成本需经营自有资金；接受新单前预览启动成本，资金不足时可分期交付、小班、商谈里程碑付款或拒单，不把保护制度设计成新手永久无法营业。它不是对现实托管法律的断言。

## 3. 账本事件与确认规则

| 事件 | 现金/资产 | 收入与义务 |
|---|---|---|
| 收课程预售或客户充值 | 现金增加，客户保护占用增加 | 未履约负债增加，收入为0 |
| 交付课程阶段或消费中转用量 | 原有现金不重复增加，对应保护释放 | 同额负债减少并确认收入 |
| 未交付退款 | 现金减少，相关保护释放 | 同额未履约负债减少；不是第二次费用 |
| 已交付后的退款/折让 | 现金减少，或冲应收 | 冲减已确认收入；额外赔偿单列费用，不伪造预付负债 |
| 供应侧预充值 | 现金减少、供应预付资产增加 | 不立即把全额当用量成本 |
| 消耗供应预付 | 预付资产减少 | 按已消耗量确认成本 |
| 后付服务与回款 | 交付先形成应收，回款再加现金 | 交付确认收入，收款不能二次确认 |
| 投资买入/卖出 | 现金与证券资产互换，费用单列 | 未实现涨幅不确认现金；卖出才记录已实现收益 |

每条业务流水包含transactionId、businessId、contractId、发生日期、账户、金额、来源事件和原流水引用。用量重复上报不重复收费；修正账单用关联更正项，不覆盖旧记录。按费率计算每笔费用时四舍五入到分，同一义务拆单不能通过反复取整创造收入。

业务利润 = 已确认收入 - 已发生成本 - 获客/平台/维护/赔付费用。现金变化另算。利润高却缺现金是允许的状态，但须展示原因。总财富不同时加入企业全部资产和玩家持有该企业的股权估值。

## 4. 订单与股权

订单保存下单检查点、最早成交点、数量、限价、预留、已成交和剩余数量。状态为pending/partially_filled/filled/cancelled/expired；部分成交只改变已成交部分，取消剩余只释放剩余占用。费用、交收、成交量和上市状态来自所选规则包；没有数据则明确拒绝，不用旧报价兜底。

原型采用标注的简化模拟制度，不声称所有A股都是相同涨跌幅或申报数量。真实历史模式须逐板块、逐日期、公司行动与价格口径核验。无融资融券、无真实交易接入；复权与分红不得重复计算。

非上市投资区分增资和老股转让。投前800万元、增资200万元，则20%新股权；对方是否融资、参与资格、治理权、优先权和退出限制分别判断。持有20%后，按投前1000万元再增资250万元、不跟投，原持股变16%。估值只是估值，不加个人现金；反事实DeepSeek投资持续标记架空。

## 5. 现金样例与零资源恢复

Q01教学：30000 + 24000工资 - 12000生活 - 3000学习 - 12000买入 = 27000元现金；持仓期末11000，则这两项合计38000，不能再加买入成本。完整按日期现金轨迹由S01测试，不只检查季末等式。

课程200人×199元，20人退款3980；交付后收入35820，平台费1791、获客6000、制作2000、支持3000，利润23029。中转收入30000、成本18000/3000/2000/1500，利润5500；另收未用充值保留负债。更多可复算样例见[规格数据](../planning/playable-spec.json)。

0行动、0可动用现金时，允许停止新增业务/撤回自己控制的授权、取消未执行计划和推进到下一检查点。这不完成调查、人工接管、旧合同交付或退款，也不撤销已发生损失。缺钱退款变到期应付；可请求代价明确的帮助、停工或清算，不能卡死。

## 6. 停业与时间线结束

业务生命周期中的paused只停新单；winding_down停止续订并处理旧义务；closed要求应交付、客户余额和应付已结清或合法转让给明确接手方。转让可能需同意、产生折价和费用；不能把负债丢给一个不存在的系统账户。

2025年末不是账目清零键。尾声列示未履约、应收、坏账准备、退款、锁定股权和待收款；可分期收尾或以明确假设计提，不按最佳行情免费变现。职业路线、破产后重新就业和退休仍可继续形成人生结局。
