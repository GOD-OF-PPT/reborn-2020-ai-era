# 02｜行动、经济与结算 v0.2

本文是统一规则契约。金额示例为虚构原型值；内部使用整数分，比例用万分比，展示换算为元。不构成税务、交易或投资指导。

## 1. 季度内时序

季度4行动点；计划只预留资源，不产生收入。开始全职工作承诺时立即消耗2点，工资按月末到账；中途辞职停止未来工资，已用行动不退。这是原型的时间抽象，不是现实劳动制度。

生活费按每月1日、工资按月末处理；项目成本、回款、退款与历史事件各自有发生日期。同日采用稳定排序：世界事件 → 已到期确定到账 → 强制付款 → 玩家可选动作 → 市场与快照结算，同类再按优先级和唯一ID排序。

仅能用已经到账且未受限的现金。季度预估盈利不能为月初投入提供透支。缺钱进入融资、减支、卖出或清算分支，不允许无限负现金；待执行的付款记为到期义务，不伪装成已付。

日期推进自动执行世界事件；不点新闻也会发生。2022年11月底出现的产品不能让10月行动获得能力加成。

## 2. 行动账本

每项动作：draft → reserved → executed → completed / interrupted。取消未执行计划释放预留；已经执行的行动与已付成本不退款，未执行的后续阶段可重排。事件可替代某项计划，但须记录替代ID，不能两边各收一次或两边都获收益。

维护也占行动：个人副业至少有配置的维护投入；雇佣团队只替代可委派工作，不使关键谈判、课程交付和本人判断全部免费。

危机不刷新季度预算。没有剩余行动时，玩家仍可发出零行动的“停止新增业务/收回可控权限”命令；它只停止可控范围的未来行为，不能免费完成调查、人工接管、追偿或撤销已生效合同。重复发出幂等。

有资源可付费求助；没有资源则让既定的最低限度响应、停工或清算规则推进到下个可行动时点。不得卡在一个只有付费行动的弹窗中。跨季继续危机才获得新季度预算，工资和原业务产出仍按实际状态计算。

## 3. 钱、收益与负债

个人和每个企业独立账户；个人副业在个人账户中按业务ID分账。注资/借款/分红必须有对应双方流水和明确性质。

界面分开：现金余额、受限/预留资金、可动用现金、应收款、客户预付款负债、应付款、投资市值、非流动股权。总资产不重复加入玩家股权价值和其对应公司的全部现金。

已收预付款不等于收入，更不等于利润。未履约部分记负债并按原型规则保护；完成交付后才释放对应额度并确认收入；退款减少现金与相应负债。客户资金不能随意挪去炒股。已确认收入但未到账时保留应收，不提前加现金。

`可动用现金 = 现金余额 - 受保护未履约预付款 - 冻结资金 - 尚未执行计划的资金预留`。不可小于0；取消计划只释放尚未支付的预留。

`业务利润 = 已确认收入 - 已发生交付成本 - 获客/平台/维护/赔付等费用`；现金变化另由流水计算。税费首版用有说明的模拟费用项，不能声称实际税后收益。

## 4. 投资与股权

A股模块使用个股订单、持仓与事件驱动行情，不以万能AI组合替代全部选择。规则/行情数据按交易市场和生效区间版本化，参见机会专项。没有核验的真实价格不得进入历史回放；模拟价格始终标记。

买入扣现金及费用并增加持仓；卖出减少持仓增加净回款；未实现涨幅不加现金。不能在已知收盘或新闻结果后按此前低价成交。停牌、涨跌停无成交量、限额和交易资格分别影响能否成交；不是“涨停一定买不到”的无条件规则。

首版无融资融券、借股做空和日内交易小游戏。个人实盘能力与游戏资金完全隔离。复权价格与分红口径只能选择一致的一套，不双计分红。

非上市项目须核实主体、融资意愿、参与资格、尽调与条款。例：投前估值800万元、新投入200万元，则投后1000万元、新投资占20%；金额不进入创始人个人消费账户，除非交易明确为老股转让且单独记账。治理权按协议判断，不由财富数值自动产生。

## 5. 可复算样例

新手季度：30000 + 24000工资 - 12000生活 - 3000学习 - 12000买入 = 27000现金。投资期末市值11000，则现金与该流动资产合计38000，不再加买入成本。月初现金必须覆盖当时支出。

企业季度：300000 - 80000项目投入 - 150000固定支出 + 60000回款 = 130000现金；这不是完整利润表。

AI卖课：200人×199元=39800收款；20人全额退款3980；其余180人全部交付后确认35820收入。平台费按退款后收入5%计算1791；获客6000、制作2000、交付支持3000；本例模拟费用前净收益23029。尚未交付时不能按这个利润提前提走资金。

API中转站：当期已消耗服务收入30000，上游18000、基础设施3000、支持2000、赔付1500，经营净收益5500；另收的未用充值不是本期收入。

预付款：收到10000、仅完成一半交付、已付成本2000，则现金8000、未履约负债5000、已确认收入5000、费用2000、可释放净额3000（假设无其他冻结/计划）。

## 6. 恢复与不变量

破产风险先说明到期义务、可用退出、损失与期限。缩减、卖资产、就业、收购都可能继续人生；公司失败不必结束游戏。生活紧绷有预警，休整有代价，不以随机重大疾病替代策略。

必须测试：账目成对、禁止未来现金、预算不超额、重复指令不重复结算、未履约资金不被消费、流量不直接当收入、股权不当现金、日期因果稳定、危机零资源可推进、恢复后不把历史损失一键清零。
