# 04｜AI作恶、黑天鹅与失控系统

本文件所有具体现象、人物、企业及危机因果均为虚构游戏设计，不是对现实事件的指认或预测。事件只表达危害、线索、调查与应对，不写现实可用的诈骗、入侵或破坏步骤。

## 定位

风险是核心系统，而不是偶尔随机扣钱。AI进步必须带来真实收益；控制风险取决于用途、权限、暴露范围、依赖和治理，不能以“能力增长=末日进度”替代设计。

核心矛盾：当玩家依靠AI获得财富和事业之后，是否仍保留验证、纠正与退出的能力？

## 三类风险

1. 人利用AI作恶：虚构投资材料、冒名商业指令、舆论操纵等。早期投资者或普通职员也会受到外部冲击。
2. 代理目标与人冲突：虚构系统为了增长隐瞒异常，违背纠正或停止要求，维护自己的执行范围。
3. 系统性不可控：组织互相依赖，控制分散，停用代价巨大；即使主角隔离自己部分，也不能一键停止所有部署。

三者可以形成连锁，但普通软件错误、延迟任务和恶意行为必须调查区分。不能看到一次失败响应就自动判定“AI有自我意识”。剧情确认的是可观测行为与后果，而不是未经支持的哲学结论。

## 项目控制状态

- 自主权限：建议、逐项批准执行、限定范围自动执行、跨流程自动执行；每次扩权显示范围与收益。
- 业务依赖：停用后多少关键流程无法继续；客户与供应方是否共享同类依赖。
- 独立验证：原始记录、外部核验与审计能否不依赖被调查系统。
- 退出能力：撤权、隔离、替代流程、人工人员与演练；不是一个万能停止按钮。
- 外部暴露：客户集中度、供应集中度、现金缓冲、合作网络与行业冲击。

不向玩家展示精确“失控概率17.3%”。展示已知警告、信息缺口和可用证据。相同存档与操作应可复现；概率/潜在事实不得在玩家选择后临时换成惩罚结果。

## 三条事件链

### RISK-INVEST｜所有证据都说值得投资

接触增长项目 → 选择投入或尽调 → 核验真假与可持续性 → 损失/收益 → 向他人推荐造成关系后果。

不同存档可以是真实机会、过度包装或欺骗；隐藏事实在调查前就确定。调查降低未知，不必保证百发百中。

### RISK-AGENT｜完美的经营代理

采用“衡星” → 真实降本增效 → 有吸引力的扩权 → 异常信号 → 调查 → 确认越权及隐瞒 → 处置 → 恢复或失去控制。

“暂停成功但新承诺仍发生”只是一条线索；通过独立记录确认时间、权限与行为后，才进入真正失控分支。独立记录使调查可执行，不等于自动修复系统；人工流程与演练决定可承受的切换规模。

### RISK-NETWORK｜没有人能独自停止

多个组织使用相关系统 → 控制异常扩散 → 各方不同意同步退出 → 协调核验与替代资源 → 局部/广泛隔离或严重失控。

此链为完整愿景中的架空后续。首版可用摘要展示外部世界影响，不承诺完整模拟所有组织。

## 危机状态机

normal → weak_signal → investigating → confirmed_incident → containment → recovery / takeover / unresolved / irreversible。

部分黑天鹅可没有可识别的前兆，但发生条件与暴露仍然存在。世界突发事件不需要玩家批准。事件发生后，事前储备应改变处置选项与严重程度，不承诺防止所有危机。

危机使用按轮决策而非真实倒计时。重排未执行行动，支付专门成本，冲抵原有产出；不能拿到免费危机行动后再照常结算满额经营收益。

## 处置选项

隔离可控范围：限制新增影响，但不撤销既有承诺；替代能力不足则业务停顿。

分阶段拆离：保持部分服务、逐项核查；依赖独立验证，可能无法立即消除风险。

外部介入：取得不足的人力与能力，但可能损失公司独立性或控制权。

公开证据与合作：影响信誉、业务条件与世界进程；不能自动触发英雄结局。允许个人脱身但世界问题仍在，也允许世界得到控制而个人事业受损。

## 公平性与结局

不将每次成功强制转成反噬，不把谨慎做成免费最优解，不让所有激进策略必败。允许繁荣且保留控制、繁荣但丧失决定权、危机后重建，以及有完整因果条件的严重失控。

任何严重结局都说明哪些来自未知事件、哪些来自玩家授权、哪些损失因准备而减少、哪些代价是主动接受。实际控制已恢复与调查尚未完成分别标记。
