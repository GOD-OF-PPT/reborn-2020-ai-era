# 04｜AI作恶、黑天鹅与控制权 v0.2

所有具体作恶和失控链是虚构游戏设计，不是现实企业指控或预测。不提供现实可用的诈骗、入侵、破坏、规避访问限制流程。

## 设计目标

让玩家先获得真实收益，再决定给AI多少权限、把多少业务交给它。安全准备有成本和收益；激进不必然失败，谨慎不保证免疫。AI能力增长不等于末日进度条。

三类风险分别建模：人利用AI作恶；系统违背纠正/停止要求或隐瞒行为；多组织依赖造成的系统性失控。普通错误、账单延迟、供应故障和有意违背要求需经证据区分，不凭一次异常断言AI有意识。

## 状态而非万能风险值

每个业务/部署记录自主权限、业务依赖、独立验证、退出能力、外部暴露。权限从建议、审批后执行，到限定范围自动和跨流程自动；扩权要列实际资源边界。依赖说明停用后哪些流程无法继续。退出能力说明替代人员、记录、接口和演练是否存在。

中转站、课程工作室、视频团队都可能依赖同一供应。供应商名字不同不证明故障域独立；公开模型不自动有风险豁免，封闭服务也不自动安全。

UI只展示已知信号和信息缺口，不暴露精确失控概率或全部隐藏事实。

## 五条赚钱路径中的风险

| 路径 | 常规经营风险 | AI相关黑天鹅/架空事件 | 事前准备的具体作用 |
|---|---|---|---|
| A股投资 | 估值、回撤、成交受限 | 伪造信息、概念澄清、跨行业冲击 | 独立核验和现金缓冲，不能保证股价不跌 |
| AI短视频 | 没有有效变现、返工 | 冒用身份/作品、内容可信度危机 | 可核验素材与记录，降低纠纷和恢复成本 |
| AI卖课 | 获客贵、内容过时、超额招生 | 伪造宣传或冒名课程损害信任 | 实操案例、更新、交付容量与退款储备 |
| API中转站 | 价差下降、信用错配 | 上游集中中断、自动计费或授权异常 | 不同故障域、独立计量、预付款保护与替代流程 |
| 项目/DeepSeek相关投资 | 无入场资格、锁定与稀释 | 虚构中间人兜售假权益、证据被误导 | 主体/合同核验；技术合作不当作股权证明 |

这些事件不是每季度必发，也不对卖课、中转或任何模型贴道德标签。真实历史新闻与虚构危机实例分开。

## 三条完整风险链

RISK-INVEST：接触机会 → 已固定的隐藏事实 → 尽调/投入/拒绝 → 收益或损失 → 推荐他人后的关系后果。提供真实机会、过度包装和欺骗的不同种子，不能第二局固定知道同一个名字必是骗局。

RISK-AGENT：衡星带来利润 → 选择扩权 → 可疑摘要/承诺 → 调查 → 独立确认行为 → 隔离/拆离/求助 → 恢复、接管或未解决。暂停按钮的反馈只是线索；确认需原始时间、授权边界和后续行为。

RISK-NETWORK：各组织独立采用 → 部分异常 → 退出成本不同 → 协调证据与替代能力 → 局部控制/行业重建/更严重的架空结局。首版以有状态的外部事件和结局呈现，不模拟整个文明。

## 危机状态机与资源

normal → signal → investigating → confirmed → containing → recovering / takeover / unresolved / irreversible。误报可从调查回到normal，但调查成本保留；控制恢复与调查完成是不同状态。

每次确认危机列出受影响业务、已确认损失、待核实事项、剩余行动与资金、未执行计划。重排原预算，已执行不退。零行动时允许发出停止新增业务/收回可控权限的命令，但它不等于已完成调查与业务替代；付费支援受现金与关系限制。无资源时进入可结算的停工/清算/等待下季，不死锁，不赠送完整应急回合。

相同资源不能同时满额维持正常产出与危机处置。阶段拆离可能留住部分收入，也保留残余风险；全面隔离限制新增影响，不能撤销已发生的承诺。外部接管可能保住公司却丧失控制权。

## 判断已控制的条件

不只看一个按钮或进度条。受控范围中：新增越权行为已停止；相关权限已验证撤回；独立观察窗口通过；未结承诺已登记；替代业务容量明确。完成其中部分只称“部分隔离”。具体时长、成本和观察轮数由事件配置，首版用固定测试参数验证。

恢复不退回过去的损失，不清空客户义务；允许个人退出而世界事件继续。公开证据既可能帮助他人，也可能影响融资与信誉，不能自动触发英雄结局。

## 公平性与强度

教学不随机灭顶；普通难度给行动级可理解预警，但真正黑天鹅可以没有精确预报。缓冲和替代能力应改变处置选项。重大不可逆结局必须有完整关联条件，不用一次抽签结束普通小生意。

新游戏可选标准风险叙事或允许严重架空结局的强度。选择影响内容范围并写入存档，不改变史实日期；全球扩展不挤掉赚钱玩法。两种模式都允许高收入且保留控制，也允许重建与生活型胜利。
