# 09｜实施路线图与交付门槛 v0.3

本页是可执行计划，不是已建立的GitHub里程碑。任务状态以[backlog](../planning/backlog.json)为准：保留P001—P022，不重编号、不因文档完成而关闭功能任务；尚未分配真实人员或创建远端Issues。

## 1. 范围不再扩张，先证明五条路线能玩

完整首版工作范围仍为2020—2025年24季度、两种背景、五条财富路线、人物与生活、一条局部历史分岔和一条局部危机。世界级失控为明确的架空扩展，不抢占核心经营交付。图像仍按第三套半写实电影感准备，原始PNG补传和正式资产验收独立。

范围缩减先减少每条路线的事件数量、美术变体和高级经营层，不删除任何一条用户明确提出的赚钱方式。正式游戏运行不需要真实开户、真卖课、实时视频生成、线上中转或真实融资。

## 4. 测试存档与可玩样板

| ID | 时间/类型 | 验证重点 |
|---|---|---|
| S01 | 2020上半年，教学 | 现金与行动、新手理解、股票模拟、没有未来能力 |

| S04 | 2025第二至第三季度，架空股权快照 | 对方意愿、拒绝、估值/稀释/治理与锁定 |
| S05 | 2025第三季度，虚构危机快照 | 有准备/无准备、0行动/0资金对照、有限撤权和恢复 |

这些是待制作测试入口，不能称为已有存档。S04的充足资金/关系明确为测试前置，不赠给普通新手；M4必须给出相应前置从正常游戏获得的路径。每个快照记录规则/内容版本、种子、日期、初始状态、命令序列和期望结果。

## 5. 每类交付的完成定义

规则：实现、单测、不变量、失败回滚与回放；内容：结构校验、来源/虚构标识、两分支、默认到期、因果回响和可达性；界面：真实操作、1366×768/1920×1080及缩放检查、键盘、错误和保存反馈；数值：逐日现金与义务、行动/产能、获客与退出，不只看正利润。

试玩观察先验证玩家赚到第一笔钱、理解现金与利润、有真实取舍、知道如何退出，再测危机和历史。预先确定工作投资、视频卖课、中转服务、架空项目投资四类策略与种子，不事后只展示最好的一局。记录破产率、资金缺口、净财富、未履约、压力、历史改变和原因，不伪造统计或固定时长。

## 6. 风险与决策闸门

真实行情未核验：继续模拟引擎，但禁称真实历史回放。美术缺图：继续灰盒，不给美术通过。玩法太繁：合并低价值操作、自动展示重复结算，不取消重要时点。债务系统过难：降低首单规模、允许里程碑交付，不删除资金保护。AI危机挤占经营：减少强危机频率与篇幅，不删掉风险系统。

同一变更同步经济、体验、事件、验收和任务。P001的规则确认是可版本化工程起点，不意味着所有金额已经被负责人验收。当前没有人员和速度数据，不编造工期或负责人；公开产品上线、支付、许可与部署另外决定。
