## 范围和实现原则

保持2020—2025年24季度、两背景、五财富路线、人物生活、一条局部历史分岔和一条局部危机；世界级架空扩展后置。缩范围先减事件变体与美术量，不删A股、视频、卖课、中转或DeepSeek。首版不做真实金融/收费/视频生成/中转后台。

竞品研究引出的重点是：首笔反馈、单工作台、路线差异、有限例行计划、准备兑现和生活回响。不是再增加几十个财务字段。经济02、内容15、技术08不变量继续有效；UI减负不能以少记账、跳事件或释放预付款实现。

## 确定的实施路径

采用串行执行基线：**规则底座 → 首季手工小单与模拟投资 → 视频 → 课程 → 中转 → DeepSeek → 历史危机与人物 → 24季度整局 → 验收与发布候选。** 来源核验、资产收集可持续推进；共同账本和命令接口先稳定，再考虑独立路线的并行实施。

E01—E18是实施切片，不是新增基础任务、Issue或已开启PR。本节登记执行顺序，实际进度以goal记录为准。每项形成独立可评审的交付与证据；必要时继续拆小，保留对应P/Q/X身份。

## 首个可玩交付的明确门槛

E09是开发验证切片，完整首版继续保留24季度、两背景和五路线。它要求：

- 技术与内容两背景均能从正常入口进入；内容背景使用独立评审的初始参数和回归，不默认照抄Q01工资。未定义的背景数据先在E01补齐。
- 玩家可保留工作、接当时可用的手工小单、选择模拟投资或自由安排；不能为获得教学奖励被迫接单或卖股。五路线显示当前准备条件，未到时代的能力不可用。
- UX01按日期通过42800/25500/800的独立回归；旧Q01保留27000；S01继续跑到2020-06-30并检查跨季、订单、现金与日序。三份证据不混为同一现金目标。
- 页面呈现可花现金、已实现收益、受保护资金、最早缺口和未履约；预览/展开/动画不改变随机或规则状态。未实现的未来经营只展示已定义门槛，不能伪装可运行选项。
- 浏览器实际验证保存/重载、重复点击、事务失败与旧档保留；0行动/0可花现金仍可有限停止和推进，不免费完成交付或调查。
- 每个结果注明Q/X的实际覆盖部分及未覆盖项。此切片不关闭完整P008/P015，不宣称W401/W402或整局完成；预试可在此开始。
