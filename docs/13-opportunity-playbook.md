# 13｜AI财富机会玩法专项

版本v0.2，2026-10-13。由用户补充的五类机会驱动；**AI卖课**为已纠正名称。下述利润、热度、客户与剧情是游戏模型，不是现实致富教程。历史日期与工具能力依据见[来源](11-historical-sources.md)。

## 共同框架：抓红利，而不只看新闻

每种机会必须具备：发现渠道、进入门槛、首笔收入、扩张手段、维护负担、衰退/转型、退出与历史影响。玩家可单走一条，也可组合；不强制成立软件公司。

机会面板展示当前可做什么、距离准备完成还缺什么、本季度最低现金点、维护行动和明确风险。产品发布、获得资格、完成适配、客户认可，是四个不同状态。

市场阶段“萌芽—红利—拥挤—成熟/替代”影响需求和获客，但阶段持续时间不是统一倒计时。对新工具的认知、实际作品、服务记录和渠道积累形成先行优势；热点收益不保证，谨慎经营也不应永远只赚零钱。

## OPP-ASTOCK｜投资A股AI股票

**入口**：资产页的A股市场，包含个股、公告、行业链与订单，不只提供一个抽象AI基金。算力设备、光通信、模型应用、数据服务等可呈现不同变化，概念热度与真实业务收入分开。

**玩法**：提前研究并小额建仓；行情来时追加、持有、减仓或卖出给副业供血；读取公司澄清、订单变化和行业新闻；遇到无法按预期成交时调整现金计划。普通看盘/调仓不耗行动，深度研究占1点，不做高频操作优势。

**先知奖励**：提前识别趋势与事件窗口；成本是等待期间的钱、回撤与错过其他生意。大方向正确仍可能买贵；记忆不能提供逐日完美买卖点。

**行情方案**：原型用明确标注的虚构A股企业与模拟行情测试机制；完整版本保留可核验的真实历史个股回放接口。没有历史数据、上市日期、停牌、公司行动和使用条件核验，不用真实股票名称配编造的价格冒充实盘。真实标的清单由P019逐项审核，而非自动选出未来涨幅冠军。

规则由市场/板块/日期决定，不能把全部A股写成统一10%涨跌幅或统一最小申报数量。季度内只在有限交易检查点执行；采用历史交易制度还是简化规则必须明确标识，不能用当前制度回填旧年份。新闻公布后的指令不允许回到公布前成交。

**风险与事件**：《概念涨了，订单在哪里》《你要用的钱被套住了》《公告：相关业务尚未形成重要收入》。虚构公司承载夸大概念的情节；不把剧本指认给真实企业。

**成长与退出**：获利转为现金、分散或支持项目。公开市场持股不自动给目标公司新增资金，也不自动影响模型路线。

## OPP-VIDEO｜AI生成短视频

**入口**：机会页新建内容账号或接一个商家视频订单。2020—2021年先积累剪辑、选题与客户；2022—2023年可逐步使用脚本、配音、图像与早期生成工具；2024年的视频生成节点带来新能力。具体工具按其发布与资格开放，不允许用后来的模型倒做2020年成片。

**生产链**：确定受众/选题 → 生成或制作素材 → 人工校正与权利核对 → 发布/交付 → 查看留存、有效咨询、付费与退款 → 更新作品库。游戏模拟这一链条，不要求运行时真的调用视频模型生成每一条作品。

**收入选择**：广告与平台分成、商单、带货佣金或引流到自有产品。各有资格与结算规则；播放量不是钱，没有变现资格可以获得曝光却没有收入。首个样板采用可核算的商单收入，随后加入流量型收入。

**操作取舍**：批量追热点获取曝光，原创系列积累受众，垂直商单获取较稳定回款。多次生成失败、返工与人物一致性问题消耗成本和交付容量；并非一次生成就自动爆款。

**风险与事件**：《爆款没有开通收益》《客户要求重做》《同质化账号涌入》《有人冒用你的作品》。2025年内容标识节点按当时制度成为流程变化，2025年具体办法不能倒扣2020年的同名违规；此前相关规则另按日期建档。

**成长与退出**：形成内容品牌/工作室、引流课程、转企业制作，或停止更新保留作品资产。流量降低的原因在结算可追溯，不随意清空粉丝。

## OPP-COURSE｜AI卖课

**入口**：掌握工具与可展示案例后设计一门课。不是“拥有AI账号就自动成为专家”，也不把卖课默认写成诈骗。

**产品选择**：低价入门课重规模，垂直实操课重案例与作业，企业内训重交付与客户关系。首笔收入来自真实课次/课程交付；预售先产生现金与履约负债，不能直接加利润。

**循环**：选学习人群和承诺 → 制作样课 → 免费内容或付费推广获客 → 招生/预售 → 授课答疑与作业反馈 → 退款、更新和转介绍。已有短视频受众可以降低获客成本，但容量有限，不能同一批人无限重复购买。

**取舍**：扩大招生还是限制班额保证交付；追新模型热点还是更新老课程；快速通识班还是较慢但可复用的行业课。没有维护的课程会因工具变化逐渐失效。营销强度不是永久收益倍率。

**会计**：收款、已交付收入、退款、平台费用、获客、制作、售后独立记账。样例见经济文档；保留下一季度答疑和退款义务。高销量可以真实赚很多钱，但大量预售也可能让玩家承担高负债。

**风险与事件**：《刚录完，工具换代了》《爆单之后谁来答疑》《买课的人没有得到承诺的帮助》。虚假宣传可以作为抽象的高风险剧情选择与投诉后果，不制作现实误导话术或假案例模板。

**成长与退出**：口碑课程库、企业培训、顾问项目或卖掉业务；课程收入不必最终导向软件创业。实用知识传播能影响工具采用，构成非资本型历史影响。

## OPP-RELAY｜做API中转站

**入口**：获得可用且适用的供应授权、基本技术和服务客户。保留“中转站”的用户熟悉名称；实际经营重点是模型服务聚合、计费、稳定性与支持，不能把卖账号/密钥或规避限制作为默认实现。

**循环**：选择供应商 → 定价或套餐 → 获客/预付与后付 → 提供实际服务 → 结算上游用量 → 支持、赔付、续费 → 改供应或转型。经营层模拟流量和账单，不需要真的搭建代理服务。

**收益**：已消耗用量的服务收入加明确的服务费，扣上游成本、基础设施、获客、支持和赔付。充值余额是负债；供应侧预付也不是已发生的用量成本。余额、已消耗成本与实际付款分别记账。

**关键取舍**：便宜单供应/较贵多供应；低价抢量/服务收费；自行维护/雇人；给客户宽信用/要求先付。低价不是没有成本的优势；多供应有迁移和适配成本，也不保证完全独立的故障域。

**红利变化**：模型降价可能先降低成本，再压低客户愿付价格；上游直销、兼容性变化和客户迁移会削弱单纯价差。玩家可以转企业账单、稳定服务、部署与支持，而非系统强制关站。

**风险与事件**：《调用量翻倍，现金更少》《上游暂停服务》《充值款不是利润》《账单与实际服务对不上》。来源不明或规则不清的供应只以抽象风险选项呈现，不提供盗号、绕过访问控制或规避限制操作。合规供应仍可能发生普通故障，不能一概归为AI作恶。

**控制权联系**：若后来把供应切换、费用授权和客户承诺交给经营代理，才进入扩权与退出能力系统；普通API转发不等同自主失控。

## OPP-DEEPSEEK｜投资DeepSeek与相关机会

此项不能被删成一句“不能投资”，也不能做成买入一个不存在的公开股票代码。

**A. 历史路径：投资其生态与应用机会。**围绕已核实的模型发布做部署服务、集成、培训、工具或核实相关企业的业务。买关联概念股、采购服务、开发生态产品均不等于持有DeepSeek股权。关系用标签明确区分：股权、合同合作、技术适配、题材关联、尚未核实。

**B. 架空路径：争取直接投资。**满足主体存在、对方融资意愿、可谈判关系、资金、尽调与条款，才出现对DeepSeek的直接投资谈判；这是玩家改变融资前提的counterfactual分支，持续显示“架空投资安排”。对方可以拒绝；可以只有小比例股权而无治理权；也可能锁定多年不能出售。没有公开可核实融资入口时，历史模式默认不提供普通人的申购按钮，不据此断言现实公司永远不会融资。

该架空安排不声称用户真实能够获得股份，不编造现实已发生轮次、估值、融资名单或退出收益。若要降低真实主体叙事风险，可使用明确的虚构研究公司承载详细条款，但保留DeepSeek真实技术节点与玩家“参与这一浪潮”的目标。

**C. 尽调事件：有人兜售所谓原始股。**卖方是虚构中间人；真假、权限和合同在玩家决定前固定。足够现金不自动让传言成为真股权；调查、拒绝或损失各有结果。风险不是DeepSeek被指认作恶。

**时间锚点**：DeepSeek-V2在2024-05-06发布，V3在2024-12-26，R1在2025-01-20；来源见H006、H008、H009。新闻、API可用性、许可证与商业投资入口分别核验，技术发布不证明融资发生。

**历史影响**：生态推广、资金支持和治理是不同层次；只有相应权利才能改变项目决策。故事中的强自主失控仍由虚构衡星系统承载，不因使用DeepSeek模型而自动触发。

## 同一事件影响五条路线

以模型能力/成本变化为例：A股市场重新评估不同企业预期；视频制作可能降本；旧课需更新但新课有需求；中转站成本和价差同时变化；部署与生态服务机会扩大。对五条路线使用同一个世界事件ID，不能各自随机宣称不同的发布日期。

玩家的选择示例：出售部分持仓支持视频商单 → 用作品形成实操课 → 将利润投向模型服务 → 行业降价时转企业部署 → 在有资格时争取项目投资。此为一种组合，不是最优攻略；全职工作通常只剩2点副业行动，不能一季度全做。

## 第一版最低交付

五类都要有入口、投入、至少两个有差别的决策、成功/受挫结果、结算与退出；DeepSeek包含历史生态路径和标识清楚的架空谈判。仅在新闻提到不算实现。每条路径至少在一个预设测试存档能独立验证，并在24季度整局中通过正常前提进入。
