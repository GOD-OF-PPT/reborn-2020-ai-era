# 40｜V3 美术交互重构、六幕大考主线与策略可玩性深度升级说明

本文档记录针对 `reborn-2020-ai-era` 在体验复盘中暴露的三大核心问题——**1. 美术交互混乱；2. 游戏主线不清晰；3. 游戏可玩性低**——所实施的 V3 系统级重构。

## 1. 痛点根因复盘

1. **美术交互混乱**：
   - React 前台（`src/ui/single-screen.css`）原采用 `100dvh + overflow: clip` 绝对定位布局，`.site-header`（`top: 0`）与 `.run-bar`（`top: 70px`）绝对悬浮，而 V2 插入的 `<MainlineCompass />` 使用 `position: relative` 置于容器顶部，导致顶栏、日期栏与主线罗盘发生像素级遮挡重叠；且 `openingRoom` 状态下隐藏了 `<MainNavigation />`，叠加多分栏横向翻页与频繁合规确认弹窗，造成操作动线迷失。
   - 独立版界面此前将 7 个同质化表单标签页平铺于灰绿底色之上，缺少空间热区、色彩语义区分与即时动态数值反馈。
2. **游戏主线不清晰**：
   - 缺少开局重生的戏剧冲突锚点、可视化的 2020—2025 六幕时间轴步进器、每幕年末量化检定节点（Boss Gate）以及竞争参照系，玩家难以感知“当下所做之事如何通往下一个时代奇点”。
3. **游戏可玩性低**：
   - 早期循环过度集中于静态按钮点击或繁琐的复式预留账目核对，缺乏每季随机手牌构筑、跨标签连携暴击、K线多空破译择时、认知科技树分支取舍以及伙伴主动支援技能。

## 2. V3 三大维度系统重构

### 2.1 美术与交互重构：「冷青暮色 × 暖珀台灯」三栏零遮挡奇点剧场

- **React 端零遮挡修复与导航常显**：重构 [src/ui/single-screen.css](../src/ui/single-screen.css) 与 [src/ui/mainline-compass.css](../src/ui/mainline-compass.css)，将 `.run-bar`（`top: 64px`）、`.mainline-compass`（`top: 114px` 悬浮毛玻璃胶囊条，展开时作为独立浮层抽屉覆盖而不挤压画布）与 `.workbench-layout`（`top: 168px`）严格分层；在 [src/ui/App.tsx](../src/ui/App.tsx) 中恢复住处状态下 `<MainNavigation />` 常显，并在首页与顶栏接入 **`✦ v3.0 奇点剧场`** 一键切换。
- **三阶房间视觉演进与场景内发光热区**：新增 2020 雪夜序章原画（`assets/ui-redesign/cinematic/era-prologue-v3.jpg`）与 2025 双屏全景 AI 极客工作室原画（`assets/ui-redesign/cinematic/room-studio-v3.jpg`），实现「寒冬出租屋 ➔ 暖光人体工学创作屋 ➔ 双屏全景极客工作室」三阶递进，并在房间画布内置书桌、副屏、书架茶席、创业蓝图四大直觉交互热区与浮动飘字反馈。

### 2.2 清晰主线架构：六幕时间轴、年末大考宝箱与宿敌镜像

- **顶栏可交互六幕时间轴**：常驻展示 `2020 微光求生` 至 `2025 时代终章` 六大篇章，随时点击可预览对应年份史实浪潮与检定标准。
- **左栏常驻大考倒计时与一键直达**：每幕设立清晰的年末净资产检定线与 3 项阶段任务（附 `[直达 →]` 一键跳转），跨年时弹出**时代幕间公报**并结算破局宝箱奖励（AI 认知点、专属增益与股权资格）。
- **宿敌镜像对比系统**：引入同期入局的焦虑风口客【赵坤（风口矩阵社）】，实时对比双方净值、口碑与暴雷风险，在 2023 黑公关交锋与 2024 算力降价洗牌中形成强烈的正反馈对照。

### 2.3 核心可玩性跃升：四大策略博弈闭环

1. **季度策略手牌 + 六大双卡连携暴击**：每季按年代动态发 5 张策略牌（支持免费灵感换牌），同季打出匹配标签组合可触发【爆款变现风暴 `[内容+商业]`】、【极客架构顿悟 `[研发+算力]`（返还 1 AP）】、【硬核降维打击 `[内容+研发]`】等 6 种高爽感连携。
2. **模拟 A 股 K 线终端 + 前世记忆破译**：内置高分屏多季度 OHLC 蜡烛图与成本线，支持消耗 `1💡 认知点`（0 AP）瞬间破译五只核心 AI 标的下季景气方向，结合每年 Q2 分红实现一二级资本共振。
3. **统一商业飞轮拓扑 + 12 节点 AI 认知科技树**：将短视频、实操营、API中转站与 DeepSeek 企业生态/架空股权整合为直观的 2×2 飞轮面板，并配套「工程算力 / 内容增长 / 心智风控」三系 12 节点永久科技树。
4. **四大挚友电影肖像支线 + 0 AP 主动支援技**：唐萤、林舟、许澄、陈屿均配备双幕分支剧情抉择及好感 ≥55 解锁的主动支援技能，搭配 Web Audio 原生合成 Lofi 氛围和弦与清脆交互音效。
