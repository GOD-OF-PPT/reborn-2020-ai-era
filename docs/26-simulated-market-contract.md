## 内容与价格口径

生产目录独立位于src/content/market.ts，严格校验后装载，不从planning加载。SIM-AI01—05分别为算力、互联、应用、数据、传媒虚构个股；SIM-EX01是2023年上市的试验应用股，另需明确模拟资格。所有名称、价格、指数、涨跌和制度均为模拟工作参数，不是现实证券、历史收益或真实开户权限。

2020—2025每月10日、20日和月末，共216个有限检查点，使用日历日。逐股逐期regime引用独立规则：交易单位、价格边界、最低佣金/费率、卖出附费、股份可售和现金交收延迟各自声明；没有把统一100股/10%限制冒充历史A股制度。规则更换时旧订单到期释放占款，必须在新行情下明确重新提交。

行情由market随机域按世界时钟生成；新闻阅读、收藏、投影、预览和下单不抽价格随机。世界锚点在自身日期发生，随后检查点的题材反应仅为模拟。经营指数与题材指数分开，不把关注度当作公司订单或现金。公开投影只含已公布行情、公告和当前规则，不返回未来检查点价格覆盖值、种子或随机流；未来撮合日历仅公开ID与日期，供明确选择订单期限。

真实历史回放持续禁用，UseHistoricalReplay返回HISTORICAL_DATA_NOT_VERIFIED；历史数据逐期覆盖、当时制度、公司行动、来源和使用条件全部核验前不能启用。没有接入行情接口、券商、真实账户或付费数据。

## 命令与有限撮合

| 命令 | 作用与边界 |
|---|---|
| PlanStockOrder | 校验账户/资格/报价ID/交易单位/限价/期限，买单预留plan资金；卖单锁定已交收股份 |
| SubmitStockOrder | 同一资金从plan转换为order，不叠加冻结；按当前报价重新检查资格和规则，取得新序号 |
| PlaceStockOrder | 同命令原子完成计划与提交，失败不留半个订单 |
| AmendStockOrder | 原子撤销剩余量、释放占款并创建替代订单；保留原成交，重排优先级与后续可撮合点 |
| CancelStockOrder | 仅释放未成交资金/股份，保留已成交费用与持仓；零行动也可执行 |
| ResearchMarket / StopMarketResearch | 独立研究耗1点、实际日期与明确费用；开始不等于资格，停止保留已耗成本与点数 |

订单必须携带当前quoteId与有限validUntil。world_update先产生行情；新订单eligibleIndex为已知行情的下一点，即使同日世界事件暂停在market_matching之前，也不能按刚看到的行情成交。此边界不依赖玩家是否点击新闻。

市场按提交序号、订单ID稳定排序，共享单股该点成交量；买限价不低于成交价、卖限价不高于成交价才可能成交。部分成交保留剩余订单和准确占款，到期释放剩余。无量、停牌、未上市、退市、未知价格/规则、无资格、过期报价、资金不足和超卖分别拒绝或记录不成交原因；不寻找旧价格兜底。缺失报价后，没有明确新参考价不能自行恢复成已知价格。

## 账务、持仓和公司行动

金额均为有界整数分，乘法和费用中间量使用BigInt。买入成本由成交本金与佣金分别记录，现金一次扣除；最低佣金按订单累计成交额计算一次，部分撤单不退已发生费用。剩余冻结额为限价剩余本金加尚需费用，价格改善后的多余占款及时释放。

股份批次记录可售日期；多个卖单不能重复锁定同一股份。卖出以加权本金和买入费用分摊，整数尾差留给最终余股，不因分次卖出丢成本。确认收入为卖出总额，费用和处置本金进入成本，未实现盈亏不记现金或已实现收入。持仓成本展示包含未摊买入费；底层投资本金与费用账各有来源。账户期间利润在买入期已确认买费；持仓含费浮盈及单笔卖出收益用于成本比较，不能再与期间利润直接相加而重复扣费。

延迟交收的卖款记录marketReceivable，纳入应收与净资产，到账前不能支持买单或生活支出；certain_receipts到期才增加现金，不重复确认收入。公司持仓、卖股订单或未结交收应收会阻止清算关闭。个人与公司分账，不用公司资金补个人消费。

只支持明确的raw_unadjusted价格：除息日按登记日前持仓确认一次分红，行情基价扣除每股分红，到账后不再确认第二次收入。登记日新买入不追领当次分红。当前未支持拆并股或真实复权口径，真实历史模式因此继续禁用。

未知当前报价时，features.market持仓valueFen/unrealizedProfitFen与根账户investmentValueFen/netAssetsFen为null，valuationStatus=data_unavailable；最后已知值另有lastKnown标签。现金仍准确显示，不能把最后已知资产值伪装为当前可变现金额。
