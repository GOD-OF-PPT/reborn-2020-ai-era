# 39｜V2 主线重构与可玩性深度优化说明

本文档总结针对 `reborn-2020-ai-era`（重生2020：AI时代）“主线不明确、游戏性不强、可玩性不高”问题的根因诊断与 V2 系统级重构方案。

## 1. 原版核心痛点诊断

1. **主线断裂与长空窗期**：[原旅程配置](../src/content/journey.ts)仅包含24句抽象散文标题；[角色档案](../src/core/player-profile.ts)中的四大愿望在局内缺少阶段性里程碑与正向回响；2020-Q1 至 2022-Q3 长达10个季度仅有 `H001` 单一历史节点，玩家极易陷入重复点击“本季工作”的目标真空。
2. **合规账本压倒游戏爽感**：[界面目录](../src/ui/App.tsx)下逾340个碎片组件围绕“预留、实付、客户保护负债、未出账应计”堆叠审计免责文本，每做一笔业务需反复预览、弹窗确认、等待、手动提交、再等待收款，微操繁琐如填报财务报表。
3. **系统割裂且缺少成长与协同**：角色缺乏跨季度能力积累与精力状态反馈，五条路线（模拟A股、AI短视频、AI卖课、API中转站、DeepSeek生态与架空股权）各自为战，未能形成清晰的商业飞轮。
4. **终局缺少成就感与重玩驱动**：[原终局页面](../src/ui/EndingStage.tsx)侧重未回收资产估算清算，缺乏多结局史诗授勋、六维人生雷达图与二周目传承机制。

## 2. V2 重构与扩充模块

### 2.1 六幕时代主线与三阶人生愿景（消除目标迷茫）

在 [src/content/mainline-chapters.ts](../src/content/mainline-chapters.ts) 与 [src/ui/mainline-projection.ts](../src/ui/mainline-projection.ts) 中建立完整的六幕时代主线：

- **第一幕 · 微光破局（2020）**：稳住本职现金流、完成 ¥1,300 手工首单或首次产业调研、安顿生活节奏。
- **第二幕 · 暗流蓄势（2021）**：构筑 ¥60,000 安全垫、参与林舟早期协作试点、升级出租屋桌椅照明。
- **第三幕 · 奇点前夜（2022）**：迎接 Stable Diffusion 与 ChatGPT 破晓，激活双路线布局与首个跨线协同。
- **第四幕 · 百模大战（2023）**：抉择林舟开源/封闭分支，应对 GPT-4 课程更新挑战，构筑口碑护城河。
- **第五幕 · 深水博弈（2024）**：切入 DeepSeek-V2/V3 与可灵视频浪潮，守住智能代理权限与客户预款边界。
- **第六幕 · 时代答卷（2025）**：冲刺 R1 生态交付或架空股权谈判，清白结清全部义务，迎接终局评定。

四大开局愿望（财务独立、经营自己的品牌、参与重要技术、保持生活自主）均升级为**三阶递进式里程碑**，实时展示达成度与阶段回响。

### 2.2 五维角色成长、身心精力与六大跨路线协同飞轮（强化策略深度）

在不破坏原有 `schema13` 确定性复式账本与存档兼容性的前提下，基于已提交公开记录实时推导：

- **五维成长**：`技术工程 (Tech)`、`内容审美 (Craft)`、`商业嗅觉 (Biz)`、`行业口碑 (Rep)`、`身心精力 (Energy)`（区分心流充沛、节奏平稳与高压透支）。
- **六大跨路线协同飞轮**：
  1. **内容私域引流飞轮**（AI短视频 × AI卖课）
  2. **开发者种子转化池**（AI短视频 × API中转站）
  3. **毕业学员企业转介**（AI卖课 × DeepSeek生态）
  4. **二级资本反哺实业**（模拟A股 × 独立企业主体）
  5. **林舟技术共创回响**（手工/视频案例 × 林舟协作线）
  6. **生活锚点与心流续航**（改善住处 × 四大人物羁绊）

### 2.3 时代主线罗盘 HUD、智能行动指引与多结局授勋殿堂（提升可玩性）

- **常驻/可折叠主线罗盘**：[src/ui/MainlineCompass.tsx](../src/ui/MainlineCompass.tsx) 提供一屏速览的章节进度、五维属性条、协同飞轮状态及**当下前2项最高价值战略行动一键直达**，大幅降低新手与中期操作摩擦。
- **原生合成轻音效**：[src/ui/sound-synth.ts](../src/ui/sound-synth.ts) 基于 Web Audio API 合成翻页、木质确认与到账提示音（默认静音，支持顶栏随时开启）。
- **S/A/B/C 多结局与六维雷达图**：[src/ui/EndingVerdictBanner.tsx](../src/ui/EndingVerdictBanner.tsx) 接入终局舞台，输出 7 类时代结局称号（如“破浪筑路者”、“复利远航家”、“灯塔创作者”、“算力守夜人”、“人间清醒客”等）及可视化六维人生雷达图。
- **独立高可玩完整重制版**：[public/playable-v2.html](../public/playable-v2.html) 内置完整的六幕24季策略卡牌经营、动态K线行情图、时代两难抉择事件链、四大人物羁绊剧情与二周目传承系统，支持零构建单文件即开即玩。
