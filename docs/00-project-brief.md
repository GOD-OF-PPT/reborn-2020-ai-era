# 00｜项目概要 v0.2

更新：2026-10-13。状态：供实施与试玩验证的设计基线，不是已完成游戏。用户的明确要求与工作默认值见[决策记录](10-decisions-and-open-questions.md)。

## 定位修正

**一个普通人重生到2020年，利用先知优势抓住AI财富浪潮，选择怎样赚钱、怎样生活，以及要不要影响这个时代。**

游戏不是必须辞职开软件公司的经营模拟。保留工作、投资A股AI股票、AI生成短视频、AI卖课、做API中转站、争取DeepSeek相关投资与合作，都应成为能辨认、能操作、能结算的路径。应用创业是其中一种组合，不是所有玩家的必经之路。

用户已纠正为“AI卖课”。全文按课程经营理解，不沿用误写词。

## 五项体验承诺

1. 先知优势真实有用：知道方向能够提前积累本金、内容、技能、客户与人脉，不以财富过高为理由随机作废记忆。
2. 第一桶金不需要先成为技术专家：不同背景都能找到可行的小规模机会；赚钱的快乐要先出现，风险不是全部内容。
3. 所有路线争夺同一份时间与现金，但形成不同能力和经营资产。流量、利润、回款、估值、控制权不能混为一谈。
4. 世界有史实底稿，也会因玩家、竞争者和技术发展而改变。玩家能通过资金、传播、技术或治理影响局部领域。
5. AI作恶与失控是有因果的核心风险，不是“发展越快必然末日”；允许繁荣且保留控制，也允许个人赚钱而世界失控。

## 产品范围与开发切片

完整首版目标调整为**2020—2025年24季度**，让视频生成、模型降本和DeepSeek相关机会拥有合理时间位置。原“2020—2023年16季度”仅保留为旧方案，不再是最终首版验收范围。

开发仍从小切片开始：一个2020年教学季度；2023年与2025年的明确测试快照；五种机会各一条可走通的经营链；一条局部历史分支；一条局部失控链。随后串联24季度。测试快照不是正式游戏免费跳年，也不自动解锁真实世界不存在的能力。

规模提案：两种起始背景、四名长期人物、五类核心赚钱机会、共享的工作/学习/关系/生活系统。应用创业、接单和技术生态使用同一项目模板，不另造五套独立游戏。全球强失控作为明确的架空后续或条件性结局，不要求模拟每个国家和企业。

## 非目标

不接入真实券商、支付或用户财务账户；不承诺现实收益；不做日内交易终端、复杂衍生品、多人交易、三维开放世界、自由装修或全程在线模型裁决。人物与经营结果默认虚构。真实企业可用于史实，虚构恶意行为不指认真实企业。

## 原型是否成立

玩家能够先靠一种非软件创业路径赚到一笔可解释的净收益；能说出为什么放弃另一条机会；能区分现金与资产；知道某次后果与自己的准备有什么关系；下一局愿意换一种赚钱组合，而不只是重复买同一只赢家股票。
