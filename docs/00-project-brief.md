# 00｜项目概要

状态：策划草案 v0.1；整理日期：2026-10-13。本文及相关文档来自本项目当前对话的整理，不是已上线产品说明。

## 原始需求

玩家重生到2020年，参与AI相关大事件并作出自己的选择；选择影响个人生存和财富；AI发展有默认轨迹，但玩家影响力足够大时也会受到玩家行动的影响。后续明确增加AI作恶黑天鹅与AI不可控事件。美术暂偏好第三套半写实电影感方案。

## 一句话定位

“重生题材的AI时代人生策略游戏”，而不是股票回测器、AI历史测验或必然走向末日的进度条。

## 三阶段体验

前期：知道方向，缺少本金、技术、客户与入场资格。用有限时间进行先行准备。

中期：拥有一些资源，却不能抓住所有机会。现金、资产、生活、承诺与独立性发生冲突。

后期：开始改变局部技术生态，部分记忆失去参考价值。AI带来真实收益，也带来滥用、目标冲突与控制问题；玩家必须判断如何继续发展、保留退出能力或承担失控代价。

## 体验支柱

1. 先知优势必须真实有用，但不能跳过现实条件。
2. 选择有机会成本；成功与失败都能追溯到原因。
3. 历史是默认路径，不是无视玩家行动的固定剧本。
4. 控制权与财富不同；谨慎不是自动胜利，激进也不必然失败。
5. 人生与世界分别结算；安稳生活、技术贡献、财富与治理影响不是同一排行榜。

## 首版收敛提案

基础篇为2020—2023年16个季度。两种起始背景、两条主要路线、四名长期人物、约五至六个历史锚点、经营与关系事件、至少一条历史分支和一条局部AI失控链。

全球性失控保留为明确标注的架空后续篇章。玩家视角长篇展示完整产品愿景，不意味着首版必须容纳所有场面。局部失控样板可以使用显式架空的中期测试存档，不能把它写成2023年发生过的真实新闻。

## 不做什么

首版不做实时股票交易、复杂衍生品、真实支付、多人对抗、自由走动的三维城市、自由装修或文明级全系统仿真。暂不把研究路线单独扩成第四套完整游戏，也不依赖在线大模型进行规则裁决。

## 判断原型是否成立

玩家能说出“我为什么放弃另一个机会”；结算后能解释现金和项目变化；看到历史分岔时知道自己影响了什么；面对AI危机时，过去的准备能形成不同的实际选项。
