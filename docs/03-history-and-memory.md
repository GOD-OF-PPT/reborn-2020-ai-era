# 03｜历史轨迹、前世记忆与因果

## 内容分类

每个事件标记为 historical（有来源的真实锚点）、fictional（普通虚构经营事件）或 counterfactual（由玩家/世界状态产生的架空分支）。这些标签在内容、界面与结局中保持一致。

无显著干预时沿默认历史；影响关键前提后，关联事件可以提前、延后、改变形态或不再发生。真实事件的实际日期单独保存，不能因架空分支改写原史实来源。

公开发布不等于主角获得API权限、客户或研发能力。能力解锁依赖当时可用工具、资格、成本、技术、合作与需求。

## 记忆卡

记忆包括明确片段、模糊方向和认知空白。每条卡片有领域、相关前提、已知事实、未知细节和参考状态：仍可参考、受到干预、已经偏离。

不能因为玩家赚得多就使全部记忆失效。一个工具生态改变，优先影响相关商业路径，不无理由改掉全部芯片公司、模型进展或人物命运。

前世已知灾难允许提前规避；记忆未覆盖的私人事件和改变历史后的新风险仍可发生。未知不是作弊，须能在事后解释风险的来源与暴露条件。

## 影响历史的资格

资助、技术贡献、关键人才关系、客户渠道、合作权或治理权，按事件具体判断。买入二级市场股票不自动获得董事会权力，也不直接等同新增研发投入。

## 首条样板分支：林舟的工具

前置：早期合作与信任；完成试用验证；团队有继续经营的资源；玩家有参与发布决策的权利。

默认路径：项目被收购，基础工具保持封闭。此默认路径同样是虚构设定，不对应真实公司的历史。

可变路径：独立开放 → 进入门槛降低 → 更多合作和开发者参与 → 竞争者也更容易出现 → 一些报价和商业机会变化。

这不是开放必然有害：合作增长和成本下降可以抵消竞争损失；封闭也不是自动安全。让玩家经营后果，而非用作者预设惩罚某种理念。

## 双时间线

左侧“前世记忆”保留原路径，右侧“当前世界”展示本局发生的事。差异有来源：由哪项决定、哪次世界事件、哪个前置条件改变引发。

因果记录建议字段：事件实例ID、季度/阶段、领域、前提、原因ID列表、变更前后状态、玩家当时可见信息和后来确认的信息。

## 世界独立推进

新闻不需要玩家阅读才发生；其他组织有自己的资源、策略与压力。不应让所有重大事件都是玩家引发，也不能让玩家永远有权阻止全球进程。

强失控故事进入显式架空篇章。不得把一个2020年的简单项目，直接描述成能够跨越所有基础条件建立文明级自主系统。
