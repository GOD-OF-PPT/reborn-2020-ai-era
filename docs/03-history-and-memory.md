# 03｜历史、记忆与机会窗口 v0.2

## 内容分层

historical：有一手来源的事实锚点；fictional：普通虚构人物、生意、价格和经营结果；counterfactual：与真实/默认前提发生分岔的安排。历史新闻和围绕它发生的虚构交易必须分别标记，不把整张卡都称为史实。

完整首版历史跨度为2020—2025年24季度。每个历史锚点保存不可改写的实际发生日期；本局实例另存发生日期、原因与偏离类型。事实日期、发布日期、内测/公开可用日期、用户获得资格的日期分开。规则变更保存生效区间，不将2025年规定反向套给2020年。

## 记忆不是股票答案库

记忆分明确片段、模糊趋势与未知细节。卡片保存领域、相关前提、已知事实、未知内容、仍可参考/受到干预/已经偏离状态。玩家知道机会方向，不等于知道每只股票每日最高最低价、每个客户的付款情况或某轮融资一定开放。

先知可以提前学习视频制作、准备课程案例、研究A股行业、建立供应与客户关系；访问权和可执行能力仍按实际时点获得。真实历史尚未发生时，可在记忆中显示模糊提示，不能把未来公告放到当期新闻。

不以身价或财富阈值全局降低记忆可靠性。改变一个部署工具，首先改变相关应用竞争和服务机会；不无理由重写全部芯片、人物和政策。

## 历史影响与经济反应分开

一次模型发布可以同时影响股票预期、视频成本、课程内容、中转价差和生态投资。用同一锚点驱动不同的经济参数；这些收益和价格反应是模拟，不是来源证明的史实。

玩家传播、客户、技术贡献、融资与治理权可以改变局部采用速度、团队生存、产品发布和合作条款。仅有股票持仓不直接提供研发资金；仅有大流量不自动取得董事会权力；仅提供采购不自动持有股权。

市场机会阶段由技术可用性、需求、竞争进入、成本和玩家局部影响共同驱动，不把所有机会固定成“一年后归零”。不用前世记忆作理由抹去竞争者的独立行动。

## 两条必须实现的分支

**林舟工具分支**：早期合作、试点验证、继续经营资源、发布参与权 → 被收购封闭/独立开放。两条都是虚构团队的路径。开放可降成本、扩合作，也会带来竞争；结局不是预定的惩罚。

**DeepSeek参与分支**：历史路线围绕已发布模型经营生态；直接股权投资需额外改变融资前提，并满足对方同意、资格、尽调和条款。这是明确架空的投资安排，不虚构历史已有公开申购入口。投资额、股权、治理权和退出权分别保存。技术发布不证明股权可购买。

## 因果记录

CauseRecord包含：事件实例ID、发生日期、领域、原因ID、状态变化、玩家当时可见证据、后续确认信息及是否为反事实。重大变化至少连接一项实际决策、世界事件或已存在的暴露条件。记录可以是多原因，禁止每次事故都归咎主角。

两条时间线：前世记忆保留原路径；当前世界呈现已发生的本局路径。未来未知分支不提前展开为完整攻略。真相在事后确认才能加入玩家可见的完整复盘；调试工具中的隐藏字段不能出现在普通UI。

## 黑天鹅与随机

记忆覆盖过的灾难可以提前应对。没经历过的私人事件、他人独立行动、历史分岔后的新组合仍可能突发。隐藏事实在机会实例生成时确定，调查只揭示已有事实，不在玩家付款后临时改成骗局。

随机按领域和实例保存稳定状态，避免看一次UI就多抽一次。实际风险发生可以不完全可预测，但暴露、严重性和恢复能力必须可解释。离线单人游戏不承诺防止玩家主动编辑存档，也不为防剧透接入账号系统。

世界级强失控进入显式架空篇章；真实DeepSeek、OpenAI等企业不承担虚构恶意代理剧情，局部失控继续由虚构衡星系统承载。
