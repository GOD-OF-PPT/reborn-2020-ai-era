# 01｜核心玩法设计 v0.2

状态：实施草案；所有容量、数值与收益均须试玩验证。修订重点：由“职业/软件创业双主线”改成“普通人的多路径AI致富与人生策略”。

## 一、核心循环

看时代与账户 → 发现机会 → 选择投入时间/本金/信誉 → 生产、交易或交付 → 到账与承担承诺 → 再投资、升级、退出或影响行业。

每季度4点个人行动；阅读与普通调仓免费，经营、学习、调查、谈判、休整收费。保留全职工作通常占2点。重大事件与危机共用预算；不能安排完4点后又免费完成三项副业。

采用季度规划、日期驱动的内部执行：计划阶段只展示已发生新闻；执行到历史日期才触发事件，允许重排尚未执行的动作。季度末不是所有费用统一发生的时点。详细时序与零行动危机处理见[经济规则](02-economy-and-actions.md)。

## 二、开局与教学

两个工作背景：技术基础较好/内容与销售基础较好；双方都拥有可维持生活的工作，不以“没有写代码能力就不能赚钱”为门槛。具体收入、地区和人物外观仍待验证。

2020年先学会看现金、安排工作、积累资金与可迁移技能。后来的模型能力只出现在记忆或尚未开放的机会卡中。不得在2020年直接经营成熟的文生视频流水线或购买DeepSeek股权。

教学固定完成一次资金规划、一项准备行动和一次结算。提供退出教学与文本模式。第一份真正副业收益可以来自小额接单，而不是强制等待多年才得到正反馈。2023年测试快照用于尽早检验赚钱体验，不替代正式时间线。

## 三、机会大厅，而不是固定职业树

| 路径 | 核心动作 | 主要经营资产 | 必须出现的取舍 |
|---|---|---|---|
| 投资A股AI股票 | 研究、选股、建仓、加减仓、退出 | 本金与研究认知 | 趋势正确但入场价、流动性与用钱时间未必正确 |
| AI生成短视频 | 选题、制作、审核、发布、接广告/商单 | 作品库、账号受众、客户 | 追热点、原创质量、产量与生成成本 |
| AI卖课 | 设计课程、获客、定价、交付、更新与退款 | 实操案例、课程、学员信任 | 招生速度与交付能力，快速变现与长期口碑 |
| 做API中转站 | 选供应、定套餐、控制用量、维护服务 | 客户、服务稳定性、供应关系 | 价差、预付款、稳定性、规则变化与依赖 |
| 投资DeepSeek相关机会 | 核实主体、尽调、谈判、投后与退出 | 股权/合作权/生态服务能力 | 看好技术不代表有融资入口，更不等于能随时卖出 |

工作、学习、生活与关系是公共底座。软件应用、企业部署和工作流咨询保留为共享项目。玩家可把短视频受众转为课程客户，把课程学员转为工具服务用户，把赚到的钱投入股票或项目，但转化要付出实际交付成本。

未注册公司时可以作为个人副业经营；需要雇佣、融资或更复杂合同后再设公司。经营载体变更应转移真实资产、合同与负债，不能把客户预付款洗成个人收入。

## 四、一个机会的生命周期

locked（缺条件）→ discoverable（可了解）→ preparing（准备）→ operating（经营）→ scaling / pivoting（扩张或转型）→ harvesting / closed（回收或结束）。

机会的市场阶段与经营阶段分开：萌芽、红利、拥挤、成熟/替代。行业到了红利期，不代表所有玩家的项目已准备好；市场成熟也不代表所有项目立即归零。

每张卡写明解锁日期和能力、最低投入、维护行动、收入来源、可见风险、现金占用、退出路径及下一次重大承诺。预览提供情景区间而非保证收益。用户未调查的事实不能以完整概率和内幕形式泄露。

## 五、深度与公平

早进入应可能形成作品、客户、品牌和采购条件的优势；不能只把“早”变成固定收益倍数。热点可能带来大钱，不必每次都变成惩罚。AI卖课不默认等于诈骗，中转站不默认等于非法，开源不默认增加失控。

技能熟练、合适渠道与稳定经营应有可行回报；押注、夸大承诺、来源不明供应等高风险决策只以游戏中的抽象策略、证据与后果呈现，不提供现实违法教程。

低资本与谨慎玩家可通过服务积累；高资本玩家仍面对机会资格和退出限制。首版不要求所有人五条路线全做。可同时持有多笔投资，但经营项目必须支付维护成本；放弃维护会缩减产出或触发已预警的客户后果。

## 六、人物、历史与生活

长期人物保留目标、信任、共同经历和承诺，不合并成万能人脉分。林舟、早期客户、关键员工与生活关系人物有自己的选择。大流量创作者能改变采用速度，可靠服务商能影响部署方式，投资者须有实际融资/治理资格才能影响研发。

AI风险贯穿每条路径：投资被概念误导，短视频遭遇伪造或权利争议，课程过时与退款，中转上游中断，代理越权及组织互相依赖。具体事件是虚构设计，不构成对真实企业的指控。

## 七、结局与节奏

结局分别展示现金、流动资产、非流动股权、持续收入、生活、关系、控制权和世界状态。安稳投资、内容品牌、课程工作室、基础服务商、创业者、技术支持者都可以完整通关。

每季度优先1个主决策、至多2个重点支线；其余信息折叠，不连续轰炸无差别弹窗。严重危机不在无前置的教学回合随机结束游戏。完整24季度的游玩时长由试玩测量，不先承诺。
