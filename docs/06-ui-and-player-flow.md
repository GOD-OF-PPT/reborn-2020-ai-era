# 06｜界面与玩家交互流程

## 入口

主菜单：新的人生、继续、存档导入/导出、设置、内容与架空说明。首次开始选择背景与人生愿望，不以了解现实AI历史作为通关门槛。

## 房间视图

展示当前生活与剧情留下的物件，提供电脑、手机、记忆笔记等入口。同时保留固定导航与键盘入口，避免必须寻找隐形热点。可跳过过渡动画。

## 季度工作台

常驻：日期、个人现金、可用行动、生活状态与当前最紧迫问题。

新闻体现世界变化；消息承载人物事件；项目页安排工作；资产页区分个人与公司；记忆页解释方向与偏离。不要一屏塞满十几张图表。

操作：拖放或点击安排行动 → 预览资金和时间 → 明确确认 → 展开执行。以按钮方式提供拖放的等价操作。阅读不收费，未执行计划可调整，重复确认不重复执行。

## 事件决策页

上方是日期、事件类型与人物/环境；中间是正文和证据入口；下方是选择、明确成本、条件和不确定性。

不满足的选项显示原因，例如缺客户、缺访问资格、现金不足或没有治理权，而不是只变灰。预测不是承诺，未知后果不写成精确概率。付费调查与普通阅读区别清楚。

## 记忆与时间线

并排展示前世默认路径和本局实际路径；点击差异查看因果。已验证的事实、模糊记忆和受到干预的片段采用不同标签。主角未知的真相不提前写进给玩家的全部事实面板。

## 危机工作台

显示已确认影响、待核实信号、剩余资源、已承诺业务与可用处置。危机按轮推进，没有逼迫快速点击的真实倒计时。已执行行动不退还，重排未执行部分必须预览原计划损失。

“已发出暂停命令”“控制台报告暂停”“独立确认停止新行为”分别表达，避免把一个UI状态等同实际控制。

## 结算页

顺序：现金去了哪里 → 项目/人物变化 → 世界影响与记忆可靠性变化 → 下季度承诺 → 保存。

每项变化有因果链接；一次性资产交易、收入、回款和估值变化分开显示。失败同样有解释与恢复选择。

## 结局页

人生、事业、关系、控制权与世界分别汇总，呈现关键决定的回放。其他路线提供少量可探索线索，不直接泄露所有隐藏结果，也不暗示存在唯一最优打法。

## 首个界面样板验收

玩家无需指导能完成一个季度；能分清现金与资产；能辨识真实与架空；能解释为什么一个选项未解锁；小屏下不遮挡主按钮、正文和结算。背景好看不能补偿操作困难。
