# 06｜界面、信息与玩家流程 v0.2

## 入口与房间

菜单：新的人生、继续、存档管理、设置、历史/架空说明。选择背景与人生愿望，不要求熟悉AI行业。房间仍用第三套半写实电影感作为暂定方向；电脑进入铺开的工作台，不把经营文字塞进透视小屏幕。房间有固定导航与可跳过动画。

## 季度工作台

顶栏保留日期、可动用个人现金、可用行动、当前生活状态和保存反馈。公司现金与预付款负债在业务页单列，不用总身价替代日常现金。

导航：新闻与消息、赚钱机会、持仓与账本、我的业务、前世记忆。主区域先显示当前最紧迫义务，再呈现可选择机会。新闻发生与是否阅读分离，红点不阻止世界推进。

## 赚钱机会页

五个明确入口：A股AI股票、AI短视频、AI卖课、API中转站、DeepSeek相关投资。未开放的入口展示准备路径和日期/资格限制，不静默隐藏用户关心的玩法。

机会卡：领域与当前市场阶段；需要的能力与关系；首次投入、维护行动、未来付款；收入来源；已知风险；观察/准备/进入/退出按钮。不能把“预计最高收入”做成默认承诺。筛选可看低本金、可兼顾工作、长期项目与现金需求，不默认推荐唯一赢家。

A股页展示个股、行情数据模式、板块、可用资金、公告、订单与成交原因；DeepSeek页明确区分生态服务、概念关联、股权投资、虚构融资谈判。历史模拟股票不能看起来像真实券商下单。

短视频页分作品、曝光、有效咨询、已确认收入与到账；课程页分招生、未交付人数、答疑容量、退款、现金与负债；中转页分客户余额、已消耗服务、上游余额/用量账单、故障和毛利。避免把几种路径全部画成相同的进度条。

## 计划与执行

点击或拖放安排行动；同时提供不依赖拖拽的按钮。确认前展示个人/公司分账的最低现金点与未履约保护额。执行后不能以取消按钮退还已发生成本。

到重大日期暂停展开事件：事件类别、已知事实、可核验证据、选择、即时成本、延迟义务和不可选原因。主动调查明确收费，普通阅读免费。发生时间之后才能使用新能力，不默认补完之前整个季度的产出。

## 危机、记忆与结算

危机页展示已发指令、系统自报状态、独立验证结果三种信息。零资源仍有停止新增业务/可控撤权或进入清算的路径，不困在无法关闭的付费弹窗。没有真实秒级倒计时。

记忆页并排显示前世与本局；未知真相不提前泄露。架空投资与失控在事件标题、时间线和结局中持续标记，不能只在第一次弹窗解释一次。

结算页按现金流水、已确认利润、非现金资产变化、客户义务、人物/历史后果、下季准备排序。每项重大变化可展开原因。不能以绿色总收益掩盖仍待支付的大额退款。

## 交互验收目标

电脑优先；以1366×768与1280×720作为首批测试视口，目标是核心操作无需横向滚动、主按钮和正文不被遮挡；这是待实现目标，不是已测结果。重要文本不烘焙入图片；颜色警告配文字；键盘可达、焦点清楚、弹窗正确恢复焦点；支持减少动态与文字模式。

加载/存档失败说明未保存状态并提供导出，不能假报成功；重复点击只生效一次。玩家不依赖开发者解释应能完成一个教学季度，分清收入/利润/现金，并指出一条机会为什么未开放。
