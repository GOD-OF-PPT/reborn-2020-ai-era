# 重生2020：AI时代

> 你依靠对未来的记忆改变命运，后来却因为自己的成功，改变了那个原本被你熟知的未来。

单人网页人生策略游戏。玩家回到2020年，在工作、投资、创业、关系和生活之间作出选择；当拥有足够的能力、合作资源和控制权后，开始改变AI发展的局部历史，也可能卷入AI作恶与失控危机。

**当前状态：策划资料初始化，不含可运行游戏。** 项目名、数值、范围及技术选型仍是工作草案。远端创建与推送状态见 [交付状态](DELIVERY-STATUS.md)，不要把本地提交当成GitHub提交。

> 美术暂定第三方案：半写实电影感。三张原始PNG仍保存在对话中的完整资料包；本次远端提交仅包含文本资料，原图尚未上传。原图信息见[资产清单](assets/concepts/manifest.json)。

## 已明确的方向

- 2020年重生；参与AI大事件；选择影响生存与财富；足够的影响力能改变历史。
- 增加AI作恶黑天鹅和AI走向不可控的事件，不只做一条赚钱曲线。
- 美术偏向第三方案：半写实、电影感、现实科技氛围。此为偏好，不是最终美术验收。
- 用GitHub管理资料和后续开发。负责人已创建公开仓库，本次保持其可见性，不修改访问权限。

## 下一项开发任务

先验证一个无精美美术的季度闭环，再验证一条真实改变后续状态的历史分支与一条局部失控事件链。不要先扩成全球末日模拟器，也不要先批量生产几十张背景图。

任务清单位于 [planning/backlog.json](planning/backlog.json)。这些是本地待办，并非已经创建的GitHub Issues。

## 本地资料检查

安装Python 3.10+后执行：

```bash
python scripts/check_docs.py --text-only
```

`--text-only`只检查文本资料、相对链接、任务依赖和JSON，并逐项报告缺少的PNG；不是完整资产校验或游戏测试。补齐原图后去掉该参数，可验证原图尺寸与哈希。
